# 心动频率研究所 · 恋爱人格 × 情侣适配度测评 H5

纯静态前端网页应用，无需任何后端服务器，双击 `index.html` 即可在电脑或手机浏览器中运行。

## 文件结构

- `index.html` — 页面骨架（首页、40 题答题页、单人报告页、双人适配度页、08 原型图鉴弹窗与 3:4 长图预览弹窗）
- `styles.css` — 编辑杂志风视觉样式、响应式布局、`纯净海报模式` 样式与 CSS 变量映射
- `config/love-quiz.config.js` — **单文件产品配置中心**（包含 `meta` 文案、`theme` 主题配色、`icons` 矢量图腾、`paywall` 可选卡密变现开关、`dimensions`、`chapters` 章节与转场里程碑、`questions` 40 题库、`archetypes` 8 大原型）
- `app.js` — **通用测评与情侣匹配引擎**（归一化计分、原型匹配、双人人格直配、URL/口令编解码、SVG 雷达图、原生 Canvas 3:4 长图渲染与微信长按保存预览）

## 功能亮点

1. **三种游玩模式**：
   - **01 单人探索**：40 道生活化场景题（带篇章转场里程碑），生成 6 维雷达图、专属金句、隐藏优势、关系盲区与生活切片彩蛋；结果页支持直接选 TA 原型或输入口令对比。
   - **02 双人直配（免答题）**：不用两个人全部答题！直接在首页分别选择双方恋爱人格原型（带实时组合预览），秒出双人适配度报告与海报。
   - **03 口令比对**：生成防篡改校验口令（`LOVE-xxx`）和带参数分享链接（`?partner=...`），两人可异地分别作答后精确比对。
2. **08 原型图鉴 & 小红书/微信分享优化**：
   - 顶栏内置「08 原型图鉴」，支持随时浏览全部 8 种恋爱人格并一键加入直配对比。
   - 支持切换「纯净海报模式」，并内置原生 Canvas 绘制 `1080×1440`（3:4）高清 PNG 长图，弹出预览层兼顾**微信/手机端长按保存相册**与**电脑端下载原图**。
3. **可选的 0.99 元售卖兑换码门禁**：
   - 默认关闭（`paywall.enabled: false`），全功能免费开放；将 `config/love-quiz.config.js` 中的 `paywall.enabled` 设为 `true` 并配置 `validCodes`，即可实现“核心海报免费看 + 输入店铺卡密解锁深度报告”。

## 如何只改 1 个文件变成新产品

只需保留 `index.html`、`styles.css` 与 `app.js` 不动，复制并修改 `config/love-quiz.config.js` 中的 `meta`、`theme`、`icons`、`dimensions`、`chapters`、`questions` 与 `archetypes`（例如换成「七宗罪人格」「小动物人格」「城市灵魂老家」「中国历史人物」），即可快速上线一套全新主题的测试产品。
